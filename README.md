# Six Traditions

A political-identity inventory for **Politics & Values, Pt. 1** (Prof. Matthew
David Hamilton, George Washington University).

Live at <https://sixtraditions.mdhamilton.com>

Twenty-four questions, four answers each. For every question the reader marks
one answer as closest to their view and one as furthest from it. The result is a
normalized profile across six traditions -- Christianity, republicanism,
liberalism, Black radicalism, feminism and conservatism -- rather than a single
label.

## What is in here

| file | what it is |
|---|---|
| `index.html` | The whole thing. One self-contained file, no build step, no server. |
| `HOW TO EDIT.txt` | How to change the questions and the tradition write-ups. |
| `CNAME` | Tells GitHub Pages which domain to serve. Do not edit or delete. |

## Editing

Everything you would normally want to change lives in two plain-text blocks near
the top of `index.html`. Read `HOW TO EDIT.txt` first.

Edit in a plain-text editor with line numbers -- BBEdit and Visual Studio Code
are both free and both fine. Do not edit it in Word, and note that TextEdit will
try to render the file as a web page rather than show you the code.

Save, then commit and push in GitHub Desktop. The live site updates about a
minute later.
